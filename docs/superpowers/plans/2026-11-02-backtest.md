# 스윙 추천 규칙 백테스트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱의 실제 `analyze_stock_for_swing`을 그대로 호출해 현재 추천 규칙(점수 60 이상 + 익절 +6.5% / 손절 -3.0% / 5영업일)을 과거 일봉 12년으로 검증하는 오프라인 도구 `backtest/`를 만든다.

**Architecture:** `일봉 캐시 → 날짜별 후보 풀 → 신호(앱 함수 호출) → 거래 시뮬레이션 → 지표·대조군·민감도 → 보고서`의 한 방향 파이프라인. 조각마다 한 가지 일만 하고 순수 함수 위주라 손으로 만든 작은 일봉으로 검증한다. 앱 코드(`backend/`)는 읽기만 한다.

**Tech Stack:** Python 3.14, pandas 3.0, pytest, 표준 라이브러리(`concurrent.futures`, `argparse`, `random`, `statistics`). 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-02-backtest-design.md`

## Global Constraints

- 새 외부 의존성을 추가하지 않는다(`pandas`는 이미 사용 중). `backend/`의 어떤 파일도 수정하지 않는다(`strategy.py` 포함). 백엔드는 import만 한다.
- 신호는 **`strategy.analyze_stock_for_swing(stock_info, candles_df)`를 그대로 호출**한다. 점수 계산을 다시 구현하지 않는다. 입력은 날짜 t까지 **최근 60봉**, `stock_info["current_price"]` = t의 종가.
- 예산 구간(후보 가격 상한): **100000, 200000, 500000**. 후보 풀: 가격 **1000원 이상** ~ 구간 상한 이하, 거래대금(종가 x 거래량) **2000백만원(20억) 이상**, 거래정지(거래량 0) 아님, 시총 목록 순서로 **앞 30개**. 목록은 코스피 150 + 코스닥 150(네이버 `marketValue` 3쪽 x 50, 코스피 먼저).
- 그날의 추천 = 점수 60 이상 통과 종목을 (점수, `risk_reward_ratio`) 내림차순 정렬한 **상위 3개**. 통과 전체를 보는 `top_n=None` 집계도 지원한다.
- 매수 가정 두 가지: `"close"`(신호일 t 종가), `"next_open"`(t+1 시가). 두 가지 모두 **t+5 영업일 종가까지** 보유(만료). 같은 종목이 보유 중 다시 신호가 나면 새 거래로 세지 않는다.
- 청산: 목표가 = `int(진입가 x orders.DEFAULT_TARGET_RATIO)`(1.065), 손절가 = `int(진입가 x orders.DEFAULT_STOP_RATIO)`(0.97). 고가가 목표가에 닿으면 **목표가 그대로** 체결(갭 상승 보너스 없음). 저가가 손절가에 닿으면 `min(시가, 손절가)`로 체결(갭 하락은 시가). **같은 날 둘 다 닿으면 손절**. 거래정지일(거래량 0)은 청산 판단에서 건너뛴다.
- 비용: `fees.calc_buy_cost`/`fees.calc_sell_proceeds`(설정값 `config.BUY_FEE_RATE` 0.00015, `SELL_FEE_RATE` 0.00015, `SELL_TAX_RATE` 0.0020)를 **1,000주 기준**으로 계산해 반올림 영향을 없앤다. 슬리피지는 진입가에 곱해 올리고 청산가에 곱해 내린다(기본 0).
- 데이터: 일봉 종목당 `count=3000`. 가격은 분할 반영, **거래량은 미반영**: 종가가 이어지는데(|등락| ≤ 35%) 앞 5봉과 뒤 5봉(해당 봉 포함)의 0이 아닌 거래량 중앙값 비가 10배 이상 또는 1/10 이하면 분할로 보고 그 **앞뒤 6봉**을 `vol_break`로 표시해 **신호에서 제외**한다(후보 풀 슬롯은 유지).
- 민감도: 익절 5.2 / 6.5 / 7.8%, 손절 2.4 / 3.0 / 3.6%, 보유 3 / 5 / 7일의 27칸 격자(슬리피지 0) + 기준 규칙에서 슬리피지 0.1 / 0.3%. 대조군: 같은 날 같은 후보 풀(30개)에서 무작위 3개, 시드 `20261102`, 20회 반복.
- 점검표 4개: 거래 100건 이상, 플러스 연도 과반, 대조군보다 기대 손익 높음, 슬리피지 0.3%에서도 기대 손익 > 0. 결론은 단정하지 않고 증거만 낸다. 보고서에 "투자 조언이 아니며 과거 성적이 미래 수익을 보장하지 않는다"와 생존 편향 한계를 적는다.
- `backtest/cache/`, `backtest/results/`는 `.gitignore`에 넣고 커밋하지 않는다. 실행은 `python -m backtest.run`.

## Review Focus

스펙이 암시하지만 개별 태스크 테스트가 따로 다루지 않기 쉬운 입력·실패 상황이다. 각 줄의 테스트는 해당 태스크에 들어 있다.

1. **상장 직후라 일봉이 25~60봉뿐인 종목**: 분석 함수가 `None`을 주거나 창이 짧아도 죽지 않고 그날 신호만 빠진다 (Task 4 `test_short_history_gives_no_signal_and_does_not_crash`).
2. **데이터 끝자락의 신호**(5영업일이 안 남음): 미완결 거래로 보고 제외한다 (Task 5 `test_unfinished_trade_near_the_end_of_data_is_dropped`).
3. **거래가 0건인 구간**: 지표가 0으로 나누지 않고 "거래 없음"으로 나온다 (Task 6 `test_empty_trades_summary_has_no_division_errors`, Task 8 `test_report_marks_empty_scenarios`).
4. **상하한가급 갭 하락 후 손절**: 손절가가 아니라 시가로 체결되어 손실이 -3%보다 크게 기록된다 (Task 5 `test_gap_down_fills_at_the_open_not_the_stop`).
5. **받기 실패·손상된 캐시 파일**: 실패 종목이 보고서에 남고 손상 파일은 다시 받는다. 실행은 중단되지 않는다 (Task 2 `test_corrupt_cache_file_is_treated_as_missing`, Task 9 `test_failed_download_is_reported_not_fatal`).

```python
def test_halt_and_index_and_sorting():
```

- [ ] **Step 1: 실패하는 테스트 작성** — `tests/test_bt_pool.py` (`frames`는 `make_frame`으로 코드별 한 날짜짜리 행을 만든다)

```python
def one(close, volume, n=3):                                  # 같은 값의 일봉 n개짜리 프레임, 마지막 날짜가 기준일
    return make_frame([(close, close, close, close, volume)] * n)

def listing(codes): return [Listing(c, c, "KOSPI", i) for i, c in enumerate(codes)]
DATE = one(10_000, 1).index[-1]

def test_filters_and_keeps_listing_order():
    frames = {"A": one(999, 10_000_000),          # 가격 미달
              "B": one(60_000, 1_000_000),         # max_price 50_000 초과
              "C": one(10_000, 199_999),           # 거래대금 1_999.99 백만 < 2_000
              "D": one(10_000, 0),                 # 거래정지
              "E": one(10_000, 300_000), "F": one(20_000, 150_000)}
    assert select_pool(listing("ABCDEF"), frames, DATE, 50_000) == ["E", "F"]

def test_boundaries_are_inclusive():
```
